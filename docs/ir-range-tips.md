# 紅外線發射距離優化

Phase 2 已能控制冷氣，但射程不夠遠時，依序檢查以下項目。

## 硬體（最重要）

| 項目 | 建議 |
|------|------|
| **VCC 接 5V** | 發射模組 VCC 接 ESP32 的 **5V / VIN**，不要接 3.3V |
| **帶放大模組** | 使用有電晶體的 IR 發射模組，不要用裸 LED |
| **對準接收窗** | IR LED 正對冷氣機身上的紅外接收窗（通常有半透明小窗） |
| **杜邦線延長** | 用母對母線把發射模組拉出來，方便調整角度 |
| **備用模組** | 若有第二顆發射模組，可並聯 DAT 腳（VCC/GND 各接各的）增加功率 |

## 軟體（Phase 2 已更新）

預設每次命令會 **連發 3 次**（模擬真實遙控器）。Serial 可調整：

```
bursts 5      # 每次命令連發 5 次（射程/可靠性↑，略增延遲）
repeat 2      # 每次 burst 內部 repeat
on
```

## 部署位置

- 客廳控制：ESP32 放在可 **直视冷气 IR 窗** 的位置
- 距離 3 公尺：5V + 放大模組 + 对准通常足够
- 避免阳光直射 IR 接收模块（学习/测试时）

## 進階（仍不够时）

- 5V 与 GND 之间加 **100–470µF 电解电容**（缓冲发射瞬间大电流）
- 使用 **5V/1A** USB 充电头供电（不要只用弱 USB 口）
- 考虑 3D 打印支架，固定 IR LED 朝向

## 你的设定（已确认）

- Protocol: `PANASONIC_AC`
- Model: `NKE`
- 发射脚: GPIO 15
